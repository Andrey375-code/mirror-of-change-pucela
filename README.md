## 1. ¿Qué es? / What is it?

Rompecabezas **cooperativo** (sin capturas, no competitivo) sobre tablero 8×8. Las negras mueven primero y las blancas último; el movimiento final de las blancas debe crear una **posición simétrica en espejo** que coincide con el «Objetivo» mostrado. Modos: **Individual** y **Con asistente** (en pareja).

A **cooperative** puzzle (no captures, non-competitive) on an 8×8 board. Black moves first and White moves last; White’s final move must create a **mirror-symmetric position** matching the displayed “Objective”. Modes: **Individual** and **With assistant** (as a pair).

## 2. Cómo ejecutar el juego

1. **Opción A (en línea, un clic):** abra <https://andrey375-code.github.io/mirror-of-change-pucela/> en cualquier navegador moderno (Chrome, Edge, Firefox, Safari), en ordenador, móvil o tableta.
2. **Opción B (sin conexión):** descargue el archivo `Mirror_of_Change_Pucela.html` y ábralo con doble clic (ordenador) o con «Abrir con» → Chrome (Android). No requiere instalación.

Al abrirlo por primera vez aparece una pantalla para **elegir idioma** (English / Español / Русский); elija **Español**. A continuación se muestran las reglas y puede empezar a jugar.

## 2. How to run the game

1. **Option A (online, one click):** open <https://andrey375-code.github.io/mirror-of-change-pucela/> in any modern browser (Chrome, Edge, Firefox, Safari) on a computer, phone or tablet.

On first launch a **language screen** appears (English / Español / Русский); choose your language. The rules are then shown and you can start playing.
